## Composition

## Resources

Declare a fixed-volume compartment with nonnegative amounts G=GSH, O=GSSG, N=NADPH and P=NADP. One peroxide-reduction reaction consumes two GSH and produces one GSSG; one glutathione-reductase reaction consumes one GSSG and one NADPH and restores two GSH; regeneration converts NADP to NADPH. Let the reaction extents per time be Jp,Jgr,Jreg. An external GSH source Jg is measured in GSH amount/time, with no other flows in this example. Then

Gdot=-2Jp+2Jgr+Jg, Odot=Jp-Jgr, Ndot=Jreg-Jgr, Pdot=Jgr-Jreg.

The code checks d(G+2O)/dt=Jg, d(N+P)/dt=0 and, for B=G/2+N, Bdot=Jreg-Jp+Jg/2. B measures peroxide-clearance equivalents, not energy or an arbitrary redox ratio. It can vanish only when both G and N vanish. Keeping B positive is necessary but not sufficient for viable chemistry: inaccessible compartmental reserves, rate limits, substrate availability and other damage are omitted.

integral(Jp) <= B(0)+integral(Jreg)+integral(Jg)/2.

This is a supplied integration theorem, not a rational-kernel proof of all trajectories. Stoichiometry is declared and must be validated for the intended physical boundary. Stoichiometric identities alone do not establish an ODE's existence or nonnegative invariance.

## Action and evidence

For a finite state set S, let A(s) be the acceptable deterministic actions at each state. A code cell C supports a single action iff intersection over s in C of A(s) is nonempty. A cover by k actions induces at most k code cells by assigning each state to an acceptable selected action. Conversely a policy on k cells uses at most k actions covering every state. Therefore minimum static code size equals minimum action cover. This elementary argument is supplied; the code exhaustively solves the stated finite instance.

For {a,b},{b,c},{a,c}, every pair intersects, but the triple does not. At least two cells are necessary, and actions a,b cover all three states. Pairwise compatibility cannot certify whole-cell compatibility. If abstain is declared acceptable everywhere and no useful-action requirement is imposed, one cell suffices. This change illustrates why safety, coverage and utility must be declared together. Randomized actions form a different library and can change the answer; the certificate does not optimize them. Recursive controller memory is not counted by this static problem.

A partial continuation descends through a quotient only when its domain is a union of whole cells and its successor quotient value is constant on every applicable cell. The example merges h0,h1 but admits a transition only at h0. Comparing successor values where both exist would pass vacuously; the domain test correctly rejects descent.

For two equiprobable states with disjoint acceptable actions and a nondisturbing diagnostic, optimal unacceptable-action selection probability is (1-TV)/2 = (1/2)sum_y min(P0(y),P1(y)). The certificate computes this exact quantity for fixed n iid Bernoulli samples with parameters3/4 and1/4. Outcomes are conditionally iid given one fixed hidden label; resampling a fresh hidden label each time is a different model. Symmetry makes the optimal majority/tie rule have equal conditional error in the two states, so its average and worst-state errors agree in this particular example.

Exact errors are5/32 at n=4,53/512 at n=6 and289/4096 at n=7. Enumeration of all counts n=0,...,6 shows none reaches1/10; n=7 does. With one observation every1/2 time unit and no free observation at0, the first acceptable fixed-count test takes7/2. The resource package excludes duration greater than2, during which at most four samples can be completed. Therefore no member of this fixed-count diagnostic family meets both conditions. At interval1/4 the seven-sample test takes7/4 and is merely not excluded. No general impossibility theorem for adaptive stopping, other diagnostic channels, altered demand or replenishment is asserted. Error here means choosing an unacceptable action, not the action's realized biological failure probability.

The evidence example binds a finite action-table calculation to the original typed query, source table, model hash and required premises, then recomputes the exact result. Required premise IDs come from the trusted local rule, not from the witness. It admits one correct witness and rejects eight targeted changes: query units, source data, result, model binding, a false premise, erased dependencies, an omitted required dependency and an absent trusted premise. ## Connection certificates

**Invariance does not remove order.** On q>0, A(q)=2q and B(q)=q+1 are injective projective maps whose admitted forward compositions remain positive. A then B gives2q+1; B then A gives2q+2. Both preserve cross ratio4/3 on q=(1,2,3,4), despite order difference1. The fixed bounded chart x=(q-1)/(q+1) also preserves cross ratio. B does not fix both interval endpoints and is not an automorphism onto the whole positive half-line; it is an admissible forward map into that domain. Thus the example lies in the general local/projective observation branch, not the endpoint-fixing UHL group. A failed commutation test is not proof of a failed scalar state.

**A gap test escapes quadratic immediate-challenge degeneracy.** In current-03, a quadratic potential G(s)=l^T s+s^T A s with common loading direction c has incremental response to challenge dose d depending on s through the one scalar c^T A s. Immediate challenge-amplitude tests may therefore collapse many genuine recovery modes. If the independently justified scalar recovery readout is m(t)=sum_i w_i exp(-lambda_i t), fixed w_i>=0,sum w_i=1, then

m(2t)-m(t)^2 = Var_w(exp(-lambda_i t)) >= 0.

At positive t, zero occurs exactly when all positively weighted attenuation factors agree. Weights1/2,1/2 and unit attenuations1/2,1/4 give m(1)=3/8,m(2)=5/32, defect1/64. A one-dimensional autonomous linear amplitude semigroup has m(s+t)=m(s)m(t), hence cannot reproduce those values. This rejects that branch, not all scalar nonlinear recovery laws. Signed weights, time-varying weights, nonlinear observation, frailty selection and recalibration can invalidate the variance interpretation. The variance identity is elementary and the multimode repair idea is longstanding; the contribution here is an executable choice of a test that the immediate quadratic challenge family cannot supply.

**Linear residue is not quadratic energy.** IDA's operational R_beta integrates displacement above a dead band against a positive leak kernel. **The pure-boost lemma needs another premise.** Let B_a(z)=(a+z)/(1+conjugate(a)z) and R_theta(z)=exp(i theta)z. This refutes the premises-to-conclusion inference **as listed in legacy-6800400 Lemma2.1**, lines314–338. It does not show that the full theorem's additional reflection covariance and loop axioms hold for this section; those may supply a repair. The full higher-dimensional classification is left as an independent proof obligation. Identity-gyration must not be defined anew as the desired pure-boost condition and then presented as a consequence of the original gyroassociative identity.
